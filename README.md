# game
マジで適当に作ったゲームたち、ついでに馬鹿適当。

## 🏛️ 近代史カードパック開封ゲーム（[game/cardgame/](game/cardgame/)）

近代史の人物177人が手に入るガチャカードゲーム。ログイン不要・ブラウザでそのまま遊べる。

- **USSR×1（スターリン専用枠）/ SSR×15 / SR×37 / R×76 / N×48** の計177枚（ヒトラー、ナポレオン、坂本龍馬、アインシュタイン、ジューコフ、ガガーリン…）
- 肖像と紹介文は [Wikipedia（ja）API](https://www.mediawiki.org/wiki/API:Main_page) からリアルタイム取得（CC BY-SA）
- 10連はSR以上1枚保証、**50連天井でSSR確定**
- チケットは10秒ごとに1枚回復（最大5枚）。重複でカードがレベルアップ（最大Lv5）
- コレクション（図鑑）とコンプ率、タグ絞り込み付き
- 開封結果のカードをタップするとその人物の詳細（Wikipedia紹介文へのリンク付き）が見られる
- **確定演出は各キャラ初回のみ**。一度見たキャラは次回から自動スキップ（バースト＋音のみ）
- **SSR以上（全員）**が出ると他のカードがフェードアウトしそのカードが画面中央へバーンと移動する確定演出。レーニン・トロツキーは15秒の専用動画（assets/confirm.mp4）が全面再生され、終わるとカード表面がフェードイン。SSR全員も assets/ssr.mp4 を置けば同じ挙動になる（無ければ映像なしでそのまま中央に表示）。スターリンは20秒の専用動画（assets/stalin.mp4）が流れ、**15秒の時点でカードが登場**し、映像終了後は最終フレームのまま静止する（動画が無い/再生不可の場合は赤背景＋ジングルにフォールバック）。毛沢東・習近平は映像（ソ連と同じconfirm.mp4を消音で流用）に合わせて中国のプロパガンダ音楽（assets/china.mp3）が鳴り、映像終了後も「閉じる」まで流れ続ける。ヒトラーは33秒の専用動画（assets/hitler.mp4）が背景で流れ、終了5秒前にカードが登場し映像終了後は最終フレームで静止（スターリンと同じ型）。映像は消音で、ドイツ軍行進曲「エーリカ」（assets/erika.mp3）を曲の1:10から鳴らし始め、「閉じる」まで流れ続ける。ヒムラーは21秒の専用動画（assets/himmler.mp4、末尾フェードアウト）が全面再生され、終わるとカード表面がフェードイン。確定演出後の「閉じる」は、まず演出を解除してカードを元の位置へ戻し、結果画面は開いたまま。もう一度押すと閉じる
- カードの裏面は人物の国ごとの模様（日本＝旭日旗、ドイツ＝ドイツ十字、ロシア＝ソビエトの星（槌と鎌）、中国＝中華蘇維埃共和国の紋章、英・米・仏・伊は国旗モチーフ、他は汎用）
- 進行状況はlocalStorageに保存。サウンド付き（ミュート可）

遊ぶ: `game/cardgame/index.html` を開くだけ。
